# Knowra

Knowra is an AI-powered document understanding and question-answering platform inspired by NotebookLM. It uses Retrieval-Augmented Generation (RAG) to help users interact with their documents, retrieve relevant information, and generate context-aware answers.

## Features
Document Understanding: Upload documents and extract their content for processing.
Retrieval-Augmented Generation (RAG): Retrieve relevant document chunks to provide context-aware answers.
Semantic Search: Find relevant information based on the meaning of user queries.
AI-Powered Question Answering: Ask questions about uploaded documents and receive contextual responses.
Interactive Interface: User-friendly interface for interacting with documents.

## Tech Stack
- Frontend	React.js
- Backend	FastAPI, Python
- AI/ML	RAG, Transformers


## How It Works
Knowra follows a Retrieval-Augmented Generation workflow:
- Document Processing: Uploaded documents are extracted and processed into text.
- Chunking: Extracted text is divided into smaller, manageable chunks.
- Embedding Generation: Text chunks are converted into vector representations.
- Retrieval: Relevant chunks are retrieved based on the user's query.
- Answer Generation: Retrieved context is used to generate relevant answers.
